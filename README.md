# 🍽️ Table — Flavors of Peru

### Cinematic Food Slider | HTML, CSS & JavaScript

An interactive restaurant experience inspired by the rich flavors of Peruvian cuisine. 🇵🇪

**Table** combines elegant design, cinematic food transitions, and smooth interactions to create a modern and immersive web experience.

No frameworks. Just HTML, CSS & JavaScript! 🚀

## ✨ Features

- 🍽️ Cinematic food transitions with smooth animations.
- 🖱️ Interactive draggable carousel with real-time movement.
- 🎨 Dynamic backgrounds and elegant typography.
- 📱 Responsive design for desktop and mobile.
- ❤️ Save favorite dishes using `localStorage`.
- 🔍 Interactive food search.
- 🎬 Food presentation video.
- ⚡ Smooth animations powered by `requestAnimationFrame`.

## 🇵🇪 Featured Dishes

- 🐟 **Ceviche Clásico** — Fresh flavors from the Peruvian coast.
- 🥩 **Lomo Saltado** — Traditional Peruvian stir-fried beef.
- 🌶️ **Ají de Gallina** — Creamy chicken with yellow chili pepper.
- 🥔 **Causa Limeña** — A delicious layered potato dish.

## 🚀 Getting Started

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Explore the dishes and enjoy the animations!

No installation, build tools, or internet connection required.

## 🎮 Interactions

Drag the carousel, click a dish, or use the arrow buttons to navigate.

The plates respond to your movement in real time, completing their cinematic transitions when a dish is selected.

Keyboard navigation is also supported.
